# Reproducing the report's figures and tables

The final report is `paper/main.tex` (Springer LNCS, same template as
`docs/archive/SSL_MSN_Report.pdf`). Its figures and tables were generated by the
scripts in `evaluation/report_scripts/`:

```
evaluation/report_scripts/
  export_wandb.py        downloads the W&B record into artifacts/wandb_export/
  wandb_results.py       recomputes every PPO score from the full W&B histories
  make_figures.py        regenerates evaluation/outputs/{figures,tables}/
  games_figure.py        games grid + games table (from the expert data / registry)
  specimen_figure.py     same, from docs/analysis/"Atari JEPA — Data Specimen Sheet.html"
  jepa_failure_probe.py  JEPA vs FSQ-VAE probe on expert vs random frames
evaluation/outputs/
  figures/               generated plots (+ PNG charts copied from jepa/charts)
  tables/                table rows (.tex) + CSVs generated from the W&B record
  results/               raw output of jepa/eval_jepa_diagnostics.py (seen / held-out games)
```

The scripts write to `evaluation/outputs/`, not into `paper/`. Copy any figure you
regenerate into `paper/figures/` (or `paper/tables/`) yourself, so the submitted
paper never changes by accident.

W&B (entity `sajid-alisadruddin-`, projects `atari-universal-feature-extractor` and
`atari-vjepa-world-model`) is the source of truth for every training run.

## Build the paper

Any TeX Live with `llncs.cls`, from inside `paper/`:

    pdflatex main && bibtex main && pdflatex main && pdflatex main

or with tectonic: `tectonic main.tex`. Overleaf also works (upload the whole folder).

## Regenerate figures and tables

From the repository root. W&B credentials come from `~/.netrc` or `WANDB_API_KEY`.

    python evaluation/report_scripts/export_wandb.py inventory
    python evaluation/report_scripts/export_wandb.py history atari-vjepa-world-model <run ids>
    python evaluation/report_scripts/export_wandb.py history atari-universal-feature-extractor <run ids>
    python evaluation/report_scripts/wandb_results.py
    python evaluation/report_scripts/make_figures.py

The history export of all 121 relevant runs takes a while (~650 MB) and skips runs that
are already downloaded. The run ids used are listed in `artifacts/wandb_export/*_runs.csv`
(all `PPO_*` runs, the autoencoder runs and the JEPA runs with more than a few steps).

`make_figures.py` also needs the diagnostics logs in `evaluation/outputs/results/`
(already present) and, for the reconstruction figure, the autoencoder checkpoints in
`artifacts/checkpoints/autoencoders/` plus the expert frames in `artifacts/data/expert/`.
To re-create the diagnostics, run from inside `jepa/`:

    python eval_jepa_diagnostics.py --checkpoint ../artifacts/checkpoints/jepa/vjepa_v2_best.pt \
        --data-dir ../artifacts/data/jepa/custom_datasets_small/val --env-mode true --num-sequences 64 \
        --output-json ../evaluation/outputs/results/val_true.json > ../evaluation/outputs/results/val_true.log
    python eval_jepa_diagnostics.py --checkpoint ../artifacts/checkpoints/jepa/vjepa_v2_best.pt \
        --data-dir ../artifacts/data/jepa/custom_datasets_small/test --env-mode unk --num-sequences 64 \
        --output-json ../evaluation/outputs/results/test_unk.json > ../evaluation/outputs/results/test_unk.log
